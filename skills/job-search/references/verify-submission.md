# Verify a job application submission — unconfirmed until proven

Distilled from `verify_job_submission` (MIT). Own words throughout.

## 1. Check the posting is still open
- Open the posting through its official apply page before tailoring a resume
  or starting a form.
- Read the page for a working apply control and for closed / expired /
  removed / no-longer-available wording.
- Stop and report the posting as closed when the page shows a closed notice,
  a 410 status, or no apply control.
- Search for another live variant of the same role when the first listing is
  closed. Treat an aggregator listing as unverified until the official
  posting confirms it is open.
- Record the posting URL, the date checked, and the exact wording that showed
  it open or closed.

## 2. Confirm the tailored resume reached the employer
- Look for a resume-upload control before submitting, and upload the tailored
  file for that posting.
- Read back the file name shown after upload and confirm it matches the
  tailored resume for that posting.
- Stop and report the substitution when no upload control exists and the
  portal will use a stored profile resume instead.
- Leave salary, location, dates, and other fields blank — or ask the user —
  when the true value is unknown. Never invent a value to pass a required field.
- Keep the tailored resume and cover letter ready for a code request, and ask
  the user for the code in the same run instead of letting it expire.

## 3. Capture the confirmation and classify follow-up mail
- Capture the exact confirmation wording shown after submit, including any
  reference number, and report it with the submission.
- Report a submission as **unconfirmed** when the page shows only an applied
  badge, a closed notice, or no confirmation wording.
- After an email application, re-check Sent and the inbox for a bounce or
  delivery-failure notice before reporting the application as submitted.
- Report the application as **not delivered** when a bounce or delivery
  failure is present, and name the bounce wording.
- **Correct the earlier report in the same conversation** when a bounce arrives
  after the submission was already reported, or when later mail changes what
  a submission or shortlist meant.
- Read follow-up mail in full before describing it. Separate an automated
  shortlist notice from an interview invite: mail counts as an interview
  invite only when it names a date, a time, a meeting link, or a named
  recruiter contact for an interview.
