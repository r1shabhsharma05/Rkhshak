# Vibe-Code Tells — the signs a screen looks AI-generated

Walk this list against the screen. List every tell, one line each, with where it lives. A screen with tells across color, type, icons, and copy needs the full unslop run. A designed screen with a few tells needs only those fixed.

## Color tells
- Purple-to-blue (violet-to-indigo) gradient — the loudest tell. Any hue gradient on a surface, gradient text, colored glows, colored shadows, radial color washes, blobs behind content, neon borders.
- Five lavenders (many near-identical tints) — nobody chose.
- Cream paper with muted earth tones used because it "feels tasteful" — the post-AI default, the way indigo was. Use only if the world demands it.
- Background that reads as orange, brown, blue, or green on a working screen (app/dashboard) — surfaces stay neutral, color lives in the content.
- Accent used everywhere instead of rarely. One accent in the chrome, covering a few percent of the screen.

## Type tells
- Uppercase labels with wide tracking (eyebrows, `NAVIGATION`, `PAID THIS MONTH`).
- One italic word inside a roman heading.
- Weights 700–900 on headings. Hierarchy from weight instead of size and color.
- Gradient text. Three or more font families.
- Centered hero headline with a greeting ("Welcome back, ... 👋").

## Icon tells
- Emoji as icons or decoration in labels (✨, 🚀, 💡). Emoji can't take the palette and read as placeholders.
- ✨ meaning AI. If AI matters, the copy says what it does.
- Icons in many sizes, strokes, and colors. One set, one size, one stroke, text-role color.
- An icon on every label. Icons that add nothing.

## Copy tells
- Greeting headlines ("Welcome back, ...!"). Exclamation marks. Hype words (supercharge, seamless, unlock, magic, revolutionize, game-changing, AI-powered on everything).
- Headlines a competitor could paste unchanged. "Powered by AI" / "Follow us for deals" filler.
- Fake proof: "Loved by 10,000+ teams", "10x faster", invented metrics, fake testimonials, logo walls, case-study counts.
- Mock content with placeholder names (Maya, Sarah, Alex, Acme, John Doe) or `[X]` / `123,456` numbers.
- Trailing periods on labels and buttons. Captions restating the heading. Subtitles under titles that say nothing the title can't.
- Badges like `PRO`, `New ✨`, `Beta 🚀` that the product doesn't need.

## Layout tells
- Everything stacked and centered. Three equal cards. Bento grids. A picture panel beside a form column.
- A card inside a card. A container inside a container inside a card.
- Dead band: empty space with no material and no job, especially on the largest viewport.
- Dividers everywhere (lines that spacing could replace). Dotted lines / dotted dividers (unless the object is really perforated).
- Two mechanisms for one job (progress bar + step counter, toast + visible change, icon + label saying the same thing).
- Bolted-on controls (a button floating beside a field instead of inside it).
- Pill badges everywhere. `rounded-2xl` as the answer to everything. Border + shadow + ring + gradient on one surface (a model hedging).

## Motion tells
- Looping pulses on things that aren't live. Shimmer on headings. Breathing glows. Parallax. `transition-all`. `hover:scale` on cards. Every section fading in on scroll.
- Motion with no narrative role.

## Content tells
- Hand-drawn browser or OS window frames. Stock illustrations, flat illustration of the product's world as the hero. Giant word above an ordinary form.
- A logo that shines (chrome orb, glossy 3D) instead of a logo that does a job.
- Characters/illustration that read as stickers or emoji (solid black masses, glove hands).

## The swap test (final audit)
Swap in another product's name. If the screen still fits, push the copy, visual, and signature harder. Name the one choice a competitor couldn't paste. No answer means the moment isn't done. Delete one more thing — if something breaks, put it back and stop.
